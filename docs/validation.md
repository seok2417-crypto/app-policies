# 검증 기록

기준일: 2026-10-19. 검증 대상은 정책 사이트이며 Android 앱이나 SDK의 실제 네트워크 개인정보 처리를 완전히 검증한 기록은 아닙니다.

## 자동 검사

- 공개 파일 12개에 대한 정적 검사 316개를 통과했습니다(`node scripts/validate.mjs`).
- HTML 3개(홈, 앱 게시 준비 안내, 404), 한국어 언어 설정, UTF-8, title/description/viewport, 한 개의 h1/main, 태그 짝/중복 id 검사를 통과했습니다.
- `/app-policies/` 접두어에서 모든 내부 링크, CSS/SVG 경로와 fragment 목적지가 정상입니다. 앱별 독립 URL 및 홈 왕복 이동도 브라우저에서 확인했습니다.
- 공개 파일은 허용 목록으로 제한합니다. 앱 소스/키/백업/APK/초안이 포함되지 않는지 검사합니다. 별도로 로컬 실제 인증정보와 공개 예정 내용을 메모리에서 비교하고 값을 출력하지 않습니다.
- script/iframe/form, inline event, 외부 CSS/이미지/폰트 요청이 없습니다. 정적 사이트 실행에는 JavaScript가 필요하지 않습니다.
- 미승인 앱의 시행일은 null이어야 하고 정식 미게시/마켓 제출 금지 안내가 있어야 하며 미완성 본문을 포함하면 검사를 실패시킵니다.

## 외부 링크

공식 참고 문서와 사이트의 외부 링크 12개 중 11개가 일반 HTTP 요청에서 200으로 응답했습니다. `guide.ncloud-docs.com/docs/apihub-overview`는 자동 요청에 403을 반환했지만 실제 브라우저에서 NAVER API HUB 개요 본문이 표시됨을 별도로 확인했습니다. 자동 검사는 이 경우 `PASS_WITH_EXTERNAL_BROWSER_REVIEW`로 남기므로 12개 모두 자동 통과했다고 해석하면 안 됩니다.

잘못된 기존 NAVER 개인정보 주소는 제거하고, 홈페이지의 실제 링크를 따라 확인한 공식 Privacy Center 문서로 연결했습니다. 2026-09-30 시행 일반 방침이 표시됩니다. 일반 방침 확인은 SDK별 모든 처리/이전 범위 확인을 대신하지 않습니다.

## 반응형·접근성

- 실제 브라우저 PC 화면(약 1086px 콘텐츠 폭)에서 레이아웃과 가로 넘침 없음을 확인했습니다.
- 브라우저 도구의 외부 viewport 변경은 실제 폭에 적용되지 않아, 로컬 QA 전용 페이지의 **실제 320/390/768px iframe viewport**에서 홈/앱 페이지 총 6개를 렌더링해 검사했습니다. 세로 스크롤바로 일부 내부 폭이 15px 작아지는 경우를 포함해 가로 넘침이 없습니다. 이 QA 페이지/서버는 공개 저장소에 포함하지 않습니다.
- 키보드 Tab으로 첫 ‘본문으로 건너뛰기’ 링크에 접근하고 Enter로 main에 포커스가 이동함을 확인했습니다.
- 주요 글자/배경 조합 5개의 명암비를 계산해 모두 4.5:1 이상임을 확인했습니다(5.96:1~13.76:1).
- 링크 이름, 제목 구조, 정보 구역 이름, 장식 이미지의 빈 alt, 키보드 포커스 스타일, 상태의 텍스트 표시를 확인했습니다. 정상 동작하는 이메일 링크를 사용합니다.
- 이 결과는 WCAG 전항목 인증이나 모든 스크린리더/실제 스마트폰 시험을 뜻하지 않습니다. 폰 기기에서 별도로 접속해 최종 확인하는 것이 좋습니다.

## 게시 및 미확정 항목

현재 앱 페이지는 준비 안내입니다. 비공개 로컬 초안은 운영자가 검토해야 하며, SDK의 세부 데이터 처리/보관과 제3자 제공·위탁·국외 이전의 실제 적용, 문의 자료 보관·권리 행사, 필요한 앱 내 고지, 최종 승인/시행일이 남아 있습니다.

GitHub Pages를 `Deploy from a branch`에 해당하는 legacy 유형, `main` / `/(root)`, HTTPS로 설정했습니다. 첫 배포의 built 상태, 공개 홈/앱 안내/CSS/SVG의 HTTP 200, 공개 홈의 브라우저 렌더링을 확인했습니다. 사이트 배포 성공이 정식 개인정보처리방침 완성을 의미하지 않습니다.

개인정보보호위원회 2026.4. 작성지침의 공식 게시 정보와 공개 정책을 참고했습니다. 첨부 PDF 자동 다운로드가 완료되지 않아 지침 PDF 전체 항목의 본문 대조는 완료하지 못했습니다. 따라서 완전한 법률 검토/작성지침 전항목 적합성을 주장하지 않습니다. 이 제한도 정식 게시 전 검토에 포함합니다.
